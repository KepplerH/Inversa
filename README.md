This code aims to bring faster and more scalable solutions to mathematical problems.
Therefore, by solving problems that lead to the use of matrices for systems of equations, 
we bring students closer to the integration of subjects such as programming and mathematics.
Linear control theory, for example, is based on representing dynamic systems using matrix equations. 
This allows engineers to design controllers that maintain system stability while optimizing performance. 
Applying determinants in this context helps determine a system's stability, 
a critical factor in the design of automated systems.
In this particular case we introduce basic concepts such as the calculation of the determinant and inverse matrix,
in the possible case (determinant different from zero).
